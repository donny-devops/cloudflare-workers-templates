# Support

## Getting Help

If you need help with this project, here are the best ways to get support:

### 📖 Documentation

- [Cloudflare Workflows Documentation](https://developers.cloudflare.com/workflows/)
- [Cloudflare Workers Documentation](https://developers.cloudflare.com/workers/)
- [Durable Objects Documentation](https://developers.cloudflare.com/durable-objects/)
- [Wrangler CLI Documentation](https://developers.cloudflare.com/workers/wrangler/)

### 🐛 Bug Reports

Found a bug? Please open an issue using our [Bug Report template](https://github.com/donny-devops/cloudflare-workers-templates/issues/new?template=bug_report.yml).

### ✨ Feature Requests

Have an idea for improvement? Use our [Feature Request template](https://github.com/donny-devops/cloudflare-workers-templates/issues/new?template=feature_request.yml).

### 💬 Community

- [Cloudflare Discord](https://discord.cloudflare.com) — General Cloudflare Workers and Workflows questions
- [Cloudflare Community Forum](https://community.cloudflare.com/) — Broader Cloudflare platform discussions

### 🔒 Security Issues

**Do not** file public issues for security vulnerabilities. Please see our [Security Policy](SECURITY.md) for responsible disclosure instructions.

## What This Project Is

This is a **starter template** demonstrating Cloudflare Workflows with real-time status updates via WebSockets and Durable Objects. It is intended as a learning resource and starting point — not a production-ready application.

## What We Can Help With

- Issues directly related to this template's code, configuration, or documentation
- Bug reports with clear reproduction steps
- Questions about adapting this template for your use case

## What's Out of Scope

- General Cloudflare Workers support (use [Cloudflare Discord](https://discord.cloudflare.com))
- Account-specific Cloudflare issues (contact [Cloudflare Support](https://support.cloudflare.com))
- Custom development or consulting requests
